# Tell - notes for coding agents

- Python 3.11, virtualenv at `.venv` (Windows: `.venv/Scripts/python`). Install: `pip install -r requirements.txt`.
- Run app: `streamlit run streamlit_app.py` (first launch seeds the demo brand into `data/tell.db` and runs the initial analysis; no API key needed).
- Tests: `pytest` (~2 min; UI smoke tests use Streamlit AppTest). Fast subset: `pytest --ignore=tests/test_ui_smoke.py` (~20 s).
- Evaluation: `python -m evaluation.run_eval --write` regenerates `EVALUATION.md`; update the README table if numbers change.
- Rule thresholds live in `tell/analysis/conventions.py`. Changing a rule's logic or threshold must bump its version there, and `data/demo/ground_truth.json` / `docs/methodology.md` must stay in sync.
- Finding keys are `rule_id:subject` and must be stable across runs (run comparison depends on it).
- Demo data is generated by `tell/data/demo_generator.py` (seed 20250101). Any change to the generator changes the data hash; re-run tests and the evaluation.
- Pages: `tell/ui/pages/{deals,overview,financial_story,operations,findings,questions,reports,copilot,data_room}.py`; navigation keys are set in `streamlit_app.py` and used by `state.go(key)`.
- Schema changes: add `CREATE TABLE IF NOT EXISTS` to `schema.sql` for new tables, or an entry in `connection.MIGRATIONS` for new columns; bump `SCHEMA_VERSION`.
- UI tokens/CSS are in `tell/ui/theme.py` and `.streamlit/config.toml`; reusable blocks in `tell/ui/components.py`; charts in `tell/ui/charts.py`. Do not add page-local CSS.
- The Windows file watcher may not reload `theme.py`; restart `streamlit run` after editing CSS.
- Streamlit 1.66: use `width="stretch"` (not `use_container_width`), never pass `height=None` to `st.dataframe`.
- Never commit `.env`, `*.db`, or `exports/`. Never add real brand names to the demo data.
